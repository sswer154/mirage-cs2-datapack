# CS2 更新包（2026-11-28）

本文只记录 **2026-11-21 之后** 的变更与当前安装产物。更早的功能说明见 [CHANGELOG.md](CHANGELOG.md) 与[数据包说明](数据包/cs2_bomb_datapack/README.md)。正式服部署以置顶的[更新日志](https://github.com/sswer154/mirage-cs2-datapack/issues/418)为准。

本期版本：`cs2fairplay 0.1.15`、`cs2grenade 0.1.1`、`cs2shop 0.1.0`、`cs2footsteps 0.1.29`。数据包与资源包本轮无结构变化。

## 一、正式赛与公平模组

- 开赛前检查在线 T/CT 队员的 `cs2fairplay` 安装、版本与比赛通信资格，按游戏 ID 逐条报告原因；中途入场、重连和训练转正式赛同样检查。（#347）
- 正式赛锁第一人称，停用主副手交换快捷键（含改键与背包内交换），限制其他模组的标准按键绑定。允许 Xaero’s World Map 及其打开地图键；Xaero 小地图与 XaeroPlus 仍在限制名单内。（#377、#379、#384）
- 参赛期间玩家体型设为 **0.937**，跨回合保持；正常结束、手动停止或离队后恢复为 **1**，离线玩家下次上线恢复。（#374）
- 加时每名参赛者在每个小回合开场重置为 **$9000**；每组 3 回合换边，先赢 4 回合获胜，3:3 后继续下一组。修复换边重复发放近战武器。（#389、#391）
- 击杀结算、比赛状态与 `WaterFreeze` 迁入公平模组，击杀播报通过 `LivingDeathEvent` 读取归属，高爆与燃烧显示对应武器名，只发给参赛者与解说。（#414）
- 管理员指令：`/cs2fairplay audit on|off|status` 控制客户端记录与赛后上传，默认关闭；`/cs2fairplay footsteps_all on|off [players]` 为非队伍玩家临时开启塔科夫脚步。

## 二、阵亡观战与操作日志

- 阵亡后左键切上一名存活队友、右键切下一名；HUD 显示当前目标或等待状态，队友全灭、掉线或离队时回当前地图大厅。解说保留自由观战。（#347）
- 观战画面展示队友第一人称手臂与 TaCZ 枪械动作，支持已同步的 YSM 2.6.5 手臂；瞄准按实际瞄具与倍率定位，切枪与换弹按连续时间采样，空手时渲染队友手臂。（#382、#385、#386、#387）
- 被观战队友的第一人称枪声按监听视角播放，其他玩家保留位置声；阵亡等待镜头或回大厅期间允许自由飞行，重连后补发镜头。（#383、#388、#393）
- 观战玩家跳过闪光遮罩与耳鸣；遮罩到期时离线玩家的清除任务保留，下次上线处理。（#299、#392）
- 操作日志双端记录，文件名包含游戏 ID 与 UUID，每位玩家每端每场最多 2 MiB；服务端存世界目录 `cs2fairplay-audit/`，客户端存实例目录，核对报告供人工复核。（#349）

## 三、客户端脚步（cs2footsteps）

- 脚步由客户端按已同步动作即时判定与播放，`cs2fairplay` 只同步声源与听众资格。生存、非旁观的 T/CT 为声源；解说可听，自身保留原版脚步。
- 状态覆盖蹲走、行走、冲刺、起跳、落地，以及 TaCZ 趴下（强制 `SWIMMING` pose 且不在水中）。趴行 **14 tick** 一步、衰减 **12 格**、增益 **0.9**。
- 材质：石（slate）、木、薄木、金属四档（实心 / metal2 / metal3 / 薄金属）、草、矮草、落叶、泥土、泥、沙、砾石、玻璃、整玻璃、雪、水、织物。每组只取塔科夫同一来源素材；草地为 `soil` + 轻 `grasslow` 混合，织物只用 `plastic`。
- 起步首步、上台阶补落地、腾空不累计步距；步频按 tick 计时，速度效果不改变间隔，水中乘 1.6 放慢；左右脚交替并带轻微随机。
- 趴下与起身播放塔科夫 `gear_sprintvault` 装备摩擦声；所有脚步与切换声使用 `EntityBoundSoundInstance` 跟随玩家，不再留在触发点。
- 同时安装 Presence Footsteps 时，客户端跳过已由 `cs2footsteps` 播放的参赛者脚步，避免叠播。（#397）
- 资源包已移除开发期的原版脚步静音覆盖；旧脚步素材迁移进客户端 JAR。（#399）

## 四、比赛流程、地图与重连

- 各地图按阵营分配多个出生点并支持查看完整坐标列表；比赛期间使用临时重生点，赛后、离队或重新上线恢复个人重生点。（#301、#305）
- 准备阶段离线、开打后重连会解除移动限制并回收商店道具；赛后才重连的参赛者先回大厅再还原背包；新比赛重置在线与离线参赛者的本场 K/D。（#296、#302、#312）
- 战术菜单触发器在入场、重连和打开菜单时补开；准备阶段商店按钮与旧聊天入口打开现行购买界面。（#303、#379）
- 训练模式暂停准备倒计时后允许移动，恢复时重新锁定；正式准备阶段在水中也保持冻结。（#306、#307）
- 投票重开清除上一轮安放的 C4；准备阶段交换副手后补发弹药盒不再覆盖枪械；正式对局禁用主副手交换快捷键以规避偶发开火卡死。（#319、#352、#384）

## 五、投掷物、C4 与枪械

- 烟雾每团显示片由 **137 张减至 93 张**，单片基础尺寸由 **7.6 增至 8.1**；落点区块未加载时暂停，连续等待 5 秒回收；烟内火格逐格熄灭。（#298）
- 燃烧弹兜底引信由 **40 tick 延长至 60 tick**，仍可碰撞提前点燃；薄板边缘按实际碰撞位置检查支撑。（#309、#317）
- 拆弹读条开始音传播范围由 **16 格扩大到 32 格**；C4 安包后关闭 T 方位置提示；C4 爆炸音上限 80 格。（#290、#304）
- 手枪主动丢出后不会被定时清理误删；准备阶段丢出的参赛枪械纳入本回合交接，拾取受栏位与背包限制时会提示；换购退款绑定实际购买者。（#300、#311、#320）
- 光标上已有商店道具时避免重复发放；$5000 战术型 SKS 同步商店、预览与测试发放数据，使用 `huanmeng:pp_762_mag` 与 `tacz:scope_elcan_4x`。（#294、#297）
- 观战玩家免受闪光遮罩与耳鸣；闪光三档音色按距离校准，40 格外不播。

## 六、文档与协作

- `AGENTS.md` 补充 GitHub Issue 标签用法、状态流转与模板默认标签；新建 Issue 需按内容选择 `bug`、`enhancement`、`documentation` 等标签。（#398）
- `sync.ps1` 按服务端/客户端分目录同步，并限制工作区与暂存范围；恢复过被覆盖的 CHANGELOG 与烟雾弹 JAR。（#338、#359）
- 数据包目录是唯一源，修改后同一次提交重打包 zip；服务端与客户端 JAR 分目录维护。

## 构建

    gradle build --no-daemon

产物在 `build/libs/`。`mirror.init.gradle` 是本地镜像配置，可删。
