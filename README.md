# CS2 更新包（2026-11-18 · 本次改动）

只列这一包相对管理员手上那版的改动。安装时替换：`cs2grenade` 模组、数据包、客户端资源包；`cs2shop` 本包内虽有一份，但内容与现网一致，换不换都行。

## 一、数据包同步

- 采纳管理员的三处手雷数值：高爆与短引线的穿透 6.0、破片 2.0、破片范围 10；碰炸手雷由 5/3/8 调整为 6/2/10。
- 删除 15 个已被模组取代的旧数据包脚本（util 下的 he、flash、smoke、fire、fuse、tick 等），`tick.mcfunction` 里对 `cs2:util/tick` 的调用一并去掉。
- 准备阶段补上「非测试局清掉测试商店绿宝石」。
- 准备阶段每 tick 幂等补齐商店钻石与默认手枪，卡顿或重连后自动修复；补发默认手枪前先清掉旧枪与弹药盒，避免叠加两把。

## 二、引信与弹道

- 闪光弹引信 50 tick 改为 30 tick（1.5 秒）。
- 烟雾弹取消引信：落点停稳（连续 3 tick 速度低于 0.12），或接触原版火、岩浆、燃烧弹火区时立刻起烟；配置保留 400 tick 兜底。
- 六个投掷物初速统一为 2.0，重力由 0.045/0.05 调整为 0.04，45 度出手落地距离比上一版更远。
  注意：投掷继承 0.8 倍移动速度，跑动中会明显超过站立投掷距离。
- 烟雾弹 `cloud_radius` 由 5.0 扩大到 6.0。
- 烟雾视觉密度提高：烟卡由 59 张（1+8+18+32）增至 137 张（1+10+24+42+60），五层分布更均匀。

## 三、闪光音色与音量

- 三档全部改用闪光自己的素材（v40_explosion3 系列），不再和手雷共用远场。
  近场：素材高通 180Hz + 高频 6dB，电平 −23.9 dB，播放音调 1.15。
  远场：同样处理，电平 −29.3 dB，音调 1.08。
  极远：同样处理，电平 −40.2 dB，音调 1.0。
- 三档素材本身按距离做过电平校准，越远越轻；40 米外不播。

## 四、拉销与引信音量

- 资源包内两条素材整体衰减一半（只降振幅，不滤波）。
- 游戏内播放音量：拉销 0.7、引信 0.55。

## 五、医疗用品的打断

- 长按不再被误判为打断：点击间隔小于 10 tick 一律视为按住。
- 打断方式：再点一次右键、按 Q、切换快捷栏、切走手上物品。
- 触发打断立刻播各自的收回音（手术包卷包收回、金星合盖），再走 1 秒前摇。

## 六、燃烧弹火区（B 方案）

- 燃烧弹不再生成真实火方块，也不会点燃建筑；火区由一组连续火点（`FireNode`）构成，位置、粒子和伤害使用同一份数据。
- 从爆点中心按四邻接 BFS 蔓延，允许同层、下降一格，或相对爆心最多向上爬升一格；超过一格的上坡、墙和台阶上方都会截断，半砖/楼梯按碰撞面高度识别。
- 火点半径 0.8 格、垂直容差 0.65 格；伤害按玩家脚部到火点的距离结算，不发射视线射线。
- 火区每 20 tick 从中心按当前半径 4→9 格重算一次；BFS 被墙截断，墙体厚度足以阻止跨墙误伤。
- 粒子为岩浆/火焰/小火/少量烟，每 2 tick 从实际火点抽样发射（12–24 个，随半径增长；最后 3 秒递减），贴地表高度。
- 伤害仍是每 0.5 秒一跳，总伤害 44（1,1,2,2,3,3,4 × 8），使用 `magic` 绕过护甲；第 7 秒最后一跳后移除火区。
- `FireBlockTracker` 只用于清理旧版本留下的真实火方块，不再记录新火区。

## 七、击杀播报与归属

- `cs2grenade` 通过 `LivingDeathEvent` 直接读取 `DamageSource`，不再使用数据包的“最近击杀者”标签。
- 同归于尽、同 tick 连杀、手雷/燃烧击杀都能正确归属；无玩家击杀者显示原版死亡信息。
- 播报会显示击杀武器：枪械读 `DamageSource.getWeaponItem()`，高爆/燃烧分别显示 `[高爆手雷]`/`[燃烧弹]`。
- K/D 由模组更新；数据包旧的 `kill_t`/`kill_ct` advancement 与 `stats/death_feed` 调用已停用。
- 击杀奖金仍由数据包 `econ/kill/on_t|on_ct` 按阵营结算，同队击杀不发奖金。
- 播报只发给 `cs2_inmatch=1` 的参赛者和 `cs2_cast` 解说。

## 八、调试日志开关

- `cs2grenade`、`cs2shop` 各自新增 common 配置，默认 `debug = false`，正常游玩只保留启动、警告与错误日志。
- 需要排查碰撞、音效、耳鸣、商店点击或指令执行时，把 `config/cs2grenade-common.toml` / `config/cs2shop-common.toml` 里的 `debug` 改成 `true`，重启服务器生效。
- 日志前缀统一为 `[cs2]` / `[cs2shop]`，方便过滤；关闭时不会输出逐 tick / 逐点击日志。

## 九、重启残留清理

- 世界重启或区块重新加载时，按实体标签清理上一局残留的手雷展示、烟片与烟罐；仍在当前局使用中的对象不会误删。
- 燃烧弹铺下的火方块写入存档 `cs2_fire_blocks`，重启或区块加载时清理，不再需要等区块常驻加载。
- 启动时有残留会输出一条 `[cs2]` 汇总；逐区块清理数量只在 `debug=true` 时输出。

## 涉及文件

- 模组：cs2grenade-0.1.0.jar（63601 字节）、cs2shop-0.1.0.jar（26130 字节）
- 数据包：cs2_bomb_datapack
- 资源包：cs2_bomb_resourcepack.zip（约 1.15 MB）

NeoForge 21.1 / MC 1.21.1，JDK 21：

    gradle build --no-daemon
